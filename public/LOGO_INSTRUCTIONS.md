# WNF Logo Setup

## Required Logo File

Place your WNF logo at: `/public/wnf-logo.png`

## Specifications

- **Filename**: `wnf-logo.png`
- **Recommended size**: 1200 x 630 pixels (optimal for WhatsApp/social media previews)
- **Format**: PNG with transparency or JPG
- **Content**: Black horse on cream/white background (as per your branding)

## Usage

This logo is used for:
1. **Open Graph previews** - When match links are shared in WhatsApp, Messages, etc.
2. **App favicon** - Browser tab icon
3. **Social media cards** - Twitter/Facebook link previews

## How to Add

1. Save your logo as `wnf-logo.png`
2. Place it in the `/public` folder
3. The app will automatically use it for all previews

## Temporary Placeholder

Until you add your logo, the app will attempt to use `/public/wnf-logo.png`.
If this file doesn't exist, social previews will show without an image.
